## ✨ About

Muse is a minimalist text animation program built with **Golang** and **GTK4**. It runs exclusively on **Linux**.

### What can you do with it?

- 🎨 Change the **font**, **color**, and **size** of the text
- ✏️ Edit the **content** on the fly
- 🎬 Render videos in **WebM** format with a **transparent background**

---

## 🚀 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/aydevix/muse
   ```

2. **Navigate into the folder**

   ```bash
   cd muse
   ```

3. **Run the program**

   ```bash
   go run .
   ```

4. **_(Optional)_** Build a single binary and run it

   ```bash
   go build -o muse . && ./muse
   ```
